# Procrastination Machine

Submit one important task. The machine produces an increasingly elaborate chain of less important tasks that suddenly feel urgent.

The Go engine models task classification, deterministic detour generation, dependency graphs, delay scoring, achievements, focus sessions, and archive statistics. The browser interface renders the live avoidance plan.

## Features

- Task-aware detours
- Five-stage dependency map
- Fake productivity and real time-loss metrics
- Recalculating distraction plans
- Achievement stamps
- Emergency five-minute focus protocol

Open `index.html` through any static web server to run the exhibit.
